# HVAC 告警监控中心 - P0-P4 优先级系统

## 📋 概述

本系统已升级为专业的P0-P4告警监控中心，提供完整的告警管理、历史追踪和统计分析功能。

## 🎯 告警优先级系统

### P0 - 紧急 (Critical) 🚨
- **颜色**: 深红色 (#dc2626)
- **含义**: 系统即将崩溃，需要立即处理
- **示例**: 
  - 热通道温度 > 45°C
  - 送风温度 > 30°C
  - 总制冷量 < 热负载的70%

### P1 - 高 (High) ⚠️
- **颜色**: 橙红色 (#ea580c)
- **含义**: 严重影响运行，需要尽快处理
- **示例**:
  - 冷通道温度 > 32°C
  - 送风温度 28-30°C
  - 制冷需求 > 95%

### P2 - 中 (Medium) ⚡
- **颜色**: 橙色 (#f59e0b)
- **含义**: 影响性能，需要关注
- **示例**:
  - 冷通道温度 30-32°C
  - 送风温度 25-28°C
  - 压缩机频率 > 88Hz

### P3 - 低 (Low) ℹ️
- **颜色**: 蓝色 (#3b82f6)
- **含义**: 轻微偏差，建议优化
- **示例**:
  - 冷通道温度 27-30°C
  - 制冷需求 70-85%
  - 压缩机频率 85-88Hz

### P4 - 信息 (Info) 💡
- **颜色**: 灰色 (#6b7280)
- **含义**: 提示信息，可选优化
- **示例**:
  - 冷通道温度 26-27°C
  - 热通道温度 37-45°C
  - 风机低速运行

## 📊 告警阈值配置

### 冷通道温度 (Room Temp)
| 温度范围 | 优先级 | 说明 |
|---------|-------|------|
| > 32°C | P1 | 严重超出标准，需立即处理 |
| 30-32°C | P2 | 超出ASHRAE推荐范围 |
| 27-30°C | P3 | 接近上限，建议关注 |
| 26-27°C | P4 | 略高，可选优化 |
| < 18°C | P4 | 过低，能源浪费 |

### 热通道温度 (RA Temp)
| 温度范围 | 优先级 | 说明 |
|---------|-------|------|
| > 45°C | P0 | 紧急状态，即将宕机 |
| 37-45°C | P4 | 略高，建议监控 |
| < 22°C | P4 | 过低，可能测量异常 |

### 送风温度 (SA Temp)
| 温度范围 | 优先级 | 说明 |
|---------|-------|------|
| > 30°C | P0 | 制冷系统可能失效 |
| 28-30°C | P1 | 制冷能力严重不足 |
| 25-28°C | P2 | 偏高，需要关注 |
| < 15°C | P2 | 过低，可能结露 |

### 制冷需求 (CFC)
| 范围 | 优先级 | 说明 |
|-----|-------|------|
| > 95% | P1 | 系统满负荷，无冗余 |
| 85-95% | P2 | 接近满负荷 |
| 70-85% | P3 | 负荷较高 |

## 🖥️ 告警监控中心功能

### 1. 实时告警面板
- **位置**: 点击右上角红色铃铛按钮打开
- **功能**:
  - 显示所有当前活跃告警
  - 按P0-P4优先级分组显示
  - 实时更新告警数量
  - 快速查看告警详情

### 2. 历史记录
- **记录内容**:
  - 告警触发时间
  - 告警清除时间
  - 告警持续时间
  - 告警状态（活跃/已清除）
- **容量**: 最多保存100条历史记录

### 3. 统计分析
#### 告警级别分布
- 柱状图显示各优先级告警数量
- 实时统计P0-P4各级别告警

#### 告警分类分布
- 饼图显示不同类别告警占比
- 分类：温度、性能、设备

#### 历史统计
- 总告警次数
- 当前活跃告警数
- 已清除告警数

## 🎨 界面功能

### 告警中心按钮
- **位置**: 右上角固定按钮
- **样式**: 红色到橙色渐变，带动画效果
- **徽章**: 显示当前告警总数（红色脉冲动画）

### 告警横幅
- **显示条件**: 存在告警时自动显示
- **内容**:
  - 最严重的告警信息
  - 各级别告警数量统计
  - 快速访问其他告警的图标
- **操作**: 点击"查看详情"打开告警详情

### 参数告警指示
- **位置**: 参数值旁边
- **样式**: 
  - 告警图标（闪烁动画）
  - 参数值颜色变为告警级别颜色
  - 右上角圆点指示器
- **操作**: 点击图标查看详细信息

## 📱 使用指南

### 查看当前告警
1. 观察右上角铃铛按钮的徽章数字
2. 点击铃铛按钮打开告警监控中心
3. 在"当前告警"标签页查看所有活跃告警
4. 告警按P0-P4优先级分组显示

### 查看告警历史
1. 打开告警监控中心
2. 切换到"历史记录"标签页
3. 查看所有告警的触发和清除时间
4. 了解告警持续时间

### 分析告警趋势
1. 打开告警监控中心
2. 切换到"统计分析"标签页
3. 查看告警级别分布图表
4. 分析告警分类占比
5. 了解历史统计数据

### 处理告警
1. 点击告警卡片或"查看详情"按钮
2. 阅读告警描述和潜在影响
3. 查看可能原因分析
4. 按照建议解决方案逐步处理
5. 调整系统参数直到告警清除

## 🔧 技术实现

### 核心文件
```
src/
├── config/
│   └── alertRules.js          # P0-P4告警规则配置
├── hooks/
│   └── useAlerts.js           # 告警管理Hook
├── components/
│   ├── AlertCenter.jsx        # 告警监控中心主界面
│   ├── WarningModal.jsx       # 告警详情模态框
│   ├── WarningBanner.jsx      # 告警横幅
│   └── ClickableParameter.jsx # 带告警的参数组件
└── App.jsx                    # 主应用（集成告警系统）
```

### 数据流
```
stats (系统状态)
  ↓
useAlerts (告警检测与历史追踪)
  ↓
{
  currentAlerts: {},      // 当前活跃告警
  alertHistory: [],       // 历史记录
  statistics: {}          // 统计信息
}
  ↓
AlertCenter / WarningBanner / ClickableParameter
  ↓
WarningModal (详细信息)
```

### 告警生命周期
1. **触发**: 参数超出阈值 → 创建告警 → 添加到历史记录
2. **活跃**: 告警持续存在 → 实时显示 → 更新统计
3. **清除**: 参数恢复正常 → 标记为已清除 → 记录清除时间和持续时间

## 📈 最佳实践

### 告警响应优先级
1. **P0告警**: 立即响应（< 5分钟）
2. **P1告警**: 紧急响应（< 15分钟）
3. **P2告警**: 快速响应（< 1小时）
4. **P3告警**: 计划响应（< 4小时）
5. **P4告警**: 定期检查（< 24小时）

### 告警管理建议
- 定期查看告警历史，了解系统运行趋势
- 关注重复出现的告警，可能需要系统优化
- 使用统计分析功能，识别系统薄弱环节
- 根据实际情况调整告警阈值
- 建立告警响应流程和责任人

### 性能优化
- 告警历史自动限制在100条以内
- 使用useMemo优化告警检测性能
- 告警状态变化时才更新历史记录
- 统计信息实时计算但缓存结果
