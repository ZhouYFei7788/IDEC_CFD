## 🎯 核心改进

### 从旧系统到新系统
| 特性 | 旧系统 | 新系统 |
|-----|-------|-------|
| 告警级别 | 3级（error/warning/info） | 5级（P0-P4） |
| 告警阈值 | 简单阈值 | 多级精细阈值 |
| 历史记录 | 无 | 完整历史追踪 |
| 统计分析 | 无 | 图表和统计 |
| 告警时间 | 无 | 触发/清除/持续时间 |
| 监控中心 | 无 | 完整的监控界面 |

### 技术优化
- ✅ 使用 `useRef` 持久化告警历史
- ✅ 使用 `useMemo` 优化性能
- ✅ 自动检测告警状态变化
- ✅ 智能的告警生命周期管理
- ✅ 响应式图表展示（recharts）

## 🚀 使用方法

### 快速开始
1. 运行项目：`npm run dev`
2. 打开浏览器：`http://localhost:5173/`
3. 点击右上角红色铃铛按钮打开告警监控中心

### 触发告警测试
1. 调整送风温度设定值到极端值（如16°C或30°C）
2. 调整室外温度到极端值（如50°C）
3. 增加机房热负载到极限值（如200kW）
4. 观察告警的触发、显示和清除

### 查看告警详情
1. 点击参数旁的告警图标
2. 或点击告警横幅的"查看详情"
3. 或在告警中心点击告警卡片

## 🔍 代码示例

### 检查告警
```javascript
import { checkAlert } from '../config/alertRules';

const alert = checkAlert('roomTemp', 33, stats, params);
// 返回：
// {
//   parameter: 'roomTemp',
//   paramName: '冷通道温度',
//   level: 'P1',
//   levelInfo: { name: 'P1-高', color: '#ea580c', ... },
//   title: '冷通道温度严重过高',
//   description: '...',
//   causes: [...],
//   solutions: [...],
//   impact: '...',
//   timestamp: 1702345678901
// }
```

### 使用告警Hook
```javascript
import { useAlerts } from './hooks/useAlerts';

const { currentAlerts, alertHistory, statistics } = useAlerts(stats, params);

// currentAlerts: { roomTemp: {...}, saTemp: {...} }
// alertHistory: [{ id, triggeredAt, clearedAt, duration, ... }]
// statistics: { total, byLevel: {P0, P1, P2, P3, P4}, ... }
```

## 📝 配置告警规则

### 添加新参数告警
```javascript
// src/config/alertRules.js
export const ALERT_RULES = {
    newParameter: {
        name: '新参数',
        unit: '单位',
        category: '分类',
        rules: [
            {
                condition: (value) => value > 100,
                level: 'P1',
                title: '新参数过高',
                description: '...',
                causes: [...],
                solutions: [...],
                impact: '...'
            }
        ]
    }
};
```

### 修改阈值
```javascript
// 修改冷通道P4阈值从26°C到25°C
{
    condition: (value) => value > 25,  // 原来是 > 26
    level: 'P4',
    // ...
}
```
