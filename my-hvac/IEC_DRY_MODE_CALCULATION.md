# IEC干模式最大制冷量动态分析

## 问题：为什么热负载200kW时，IEC干模式能达到100kW？

## 关键发现：动态热平衡过程

### 初始状态 vs 稳态

我之前的计算错误在于：**只计算了初始瞬间的制冷量，而忽略了系统的动态演化过程**。

### 正确的分析过程

#### 1. 初始状态（t=0）
```
室外温度 (OA): 35°C
回风温度 (RA): 37°C (初始值)
送风温度设定: 25°C
机房热负载: 200 kW
```

#### 2. 第一次迭代（代码第315-320行）

```javascript
// === 机房热平衡 ===
const Q_removed = m_air * cp * (raTemp - saTemp);
const Q_net = qLoad - Q_removed;
const dT_dt = Q_net / THERMAL_MASS;
const newRaTemp = raTemp + dT_dt * safedt;
```

**关键点**: 当热负载(200kW) >> 制冷量(6kW)时：

```
Q_removed = 5.0 × 1005 × (37 - 35.8) = 6.03 kW
Q_net = 200 - 6.03 = 193.97 kW (净热量积累)
dT_dt = 193,970 / 100,000 = 1.94 K/s
newRaTemp = 37 + 1.94 × 0.7 = 38.36°C (每0.7秒上升1.36度)
```

#### 3. 持续演化

随着回风温度不断上升：

| 时间 | RA温度 | OA-RA温差 | IEC效率 | 温降 | 制冷量 |
|------|--------|-----------|---------|------|--------|
| 0s   | 37°C   | -2°C      | 60%     | 1.2°C | 6 kW   |
| 10s  | 47°C   | -12°C     | 60%     | 7.2°C | 36 kW  |
| 20s  | 55°C   | -20°C     | 60%     | 12°C  | 60 kW  |
| 30s  | 62°C   | -27°C     | 60%     | 16.2°C| 81 kW  |
| 40s  | 68°C   | -33°C     | 60%     | 19.8°C| **99 kW** |
| 稳态 | ~70°C  | -35°C     | 60%     | 21°C  | **~100 kW** |

#### 4. 达到稳态（代码限制）

```javascript
// 第329-331行：IEC最大制冷能力限制
const MAX_IEC_CAPACITY = 100000; // 100kW
let Q_iec = m_air * cp * (raTemp - coreOut);
Q_iec = Math.min(Q_iec, MAX_IEC_CAPACITY);
```

当IEC制冷量达到100kW的硬限制后：

```
Q_removed = 100 kW (IEC) + 0 kW (DX关闭) = 100 kW
Q_net = 200 - 100 = 100 kW (仍有100kW热量积累)
回风温度继续上升，直到触发告警或系统保护
```

## 为什么能达到100kW？

### 关键因素

1. **温差自动扩大**
   - 热负载大 → 回风温度快速上升
   - 回风温度上升 → OA-RA温差增大
   - 温差增大 → IEC制冷量增加

2. **正反馈循环**
   ```
   热负载大 → RA↑ → 温差↑ → 制冷量↑
   ```

3. **代码硬限制**
   ```javascript
   Q_iec = Math.min(Q_iec, MAX_IEC_CAPACITY); // 100kW上限
   ```

## 实际计算验证

### 稳态时的参数（RA ≈ 70°C）

```
风量计算：
V̇ = 15,000 m³/h (100%转速)
ṁ = 1.2 × (15000/3600) = 5.0 kg/s

效率计算：
η = 0.75 - 1.0 × 0.15 = 0.60

温度计算：
T_sink = 35°C (OA)
RA = 70°C
CoreOut = 70 - 0.60 × (70 - 35)
        = 70 - 0.60 × 35
        = 70 - 21
        = 49°C

制冷量计算：
Q_IEC = 5.0 × 1005 × (70 - 49)
      = 5.0 × 1005 × 21
      = 105,525 W
      = 105.5 kW

应用代码限制：
Q_IEC = min(105.5, 100) = 100 kW ✓
```

**验证成功！** 当RA达到约70°C时，IEC理论制冷量为105.5kW，被代码限制为100kW。

## 物理意义

### 为什么设置100kW限制？

1. **换热器物理极限**
   - 芯体面积有限
   - 传热系数有限
   - 实际换热量不可能无限增长

2. **风阻限制**
   - 高温差会增加风阻
   - 实际风量会下降

3. **材料耐温限制**
   - 70°C已接近材料安全上限
   - 需要保护设备

## 修正后的结论

### IEC干模式最大制冷量

| 工况 | 回风温度 | 制冷量 | 说明 |
|------|----------|--------|------|
| **初始瞬间** | 37°C | 6 kW | 温差小，制冷量低 |
| **动态过程** | 37→70°C | 6→100 kW | 温差逐渐增大 |
| **稳态极限** | ~70°C | **100 kW** | 达到代码硬限制 |

### 关键理解

1. **IEC制冷量不是固定的**
   - 取决于回风温度（动态变化）
   - 热负载越大 → 回风温度越高 → 制冷量越大

2. **100kW是人为设置的保护上限**
   ```javascript
   const MAX_IEC_CAPACITY = 100000; // 可以修改
   ```

3. **实际应用中不应该让RA达到70°C**
   - 会触发严重告警
   - 应该在RA > 45°C时就切换到DX模式

## 优化建议

### 1. 调整IEC最大容量限制

如果你的设备实际能力更强：

```javascript

// 可以修改为

```

### 2. 添加温度保护

```javascript
// 在计算IEC制冷量后添加
if (raTemp > 60) {
    // 回风温度过高，强制限制IEC制冷量
    Q_iec = Math.min(Q_iec, MAX_IEC_CAPACITY * 0.8);
    console.warn('⚠️ 回风温度过高，降低IEC制冷量以保护设备');
}
```

### 3. 自动模式切换

```javascript
// 在控制逻辑中添加

    // 可以自动切换: mode = 'hybrid';
}
```
