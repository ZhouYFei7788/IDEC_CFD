## 主要改进

### 1. IEC额定容量调整

**之前（简化模型）:**
```javascript
const MAX_IEC_CAPACITY = 100000; // 100kW 硬限制
```

**现在（真实模型）:**
```javascript
const IEC_RATED_CAPACITY = 60000;  // 60kW 额定容量
const IEC_MAX_OVERLOAD = 1.2;      // 最多超载20%
const MAX_IEC_CAPACITY = 72000;    // 72kW 绝对上限
```

### 2. 高温下风量下降

**新增物理限制:**
```javascript
// 回风温度 > 50°C 时
if (raTemp > 50) {
    const tempPenalty = Math.min((raTemp - 50) * 0.015, 0.3);
    airflow_m3h = airflow_m3h * (1 - tempPenalty);  // 最多降低30%
    m_air = flow_m3s * rho * (1 - tempPenalty * 0.5);
}
```


| 回风温度 | 风量衰减 | 实际风量 |
|---------|---------|---------|
| 50°C | 0% | 15,000 m³/h |
| 60°C | 15% | 12,750 m³/h |
| 70°C | 30% | 10,500 m³/h |

### 3. 高温下换热效率下降

**新增物理限制:**
```javascript
// 回风温度 > 50°C 时
if (raTemp > 50) {
    const effPenalty = Math.min((raTemp - 50) * 0.02, 0.4);
    efficiency = efficiency * (1 - effPenalty);  // 最多降低40%
}

// 回风温度 > 70°C 时（设备保护）
if (raTemp > 70) {
    efficiency = efficiency * 0.5;  // 强制降低50%
    console.warn('⚠️ 设备保护模式启动');
}
```

| 回风温度 | 效率衰减 | 实际效率 (干模式100%风速) |
|---------|---------|------------------------|
| 50°C | 0% | 60% |
| 60°C | 20% | 48% |
| 70°C | 40% + 50% | 18% |

### 4. DX系统高温保护

**新增物理限制:**
```javascript
// 回风温度 > 60°C 时，DX效率也会下降
if (raTemp > 60) {
    const dxPenalty = Math.min((raTemp - 60) * 0.01, 0.2);
    Q_dx_actual = Q_dx_actual * (1 - dxPenalty);  // 最多降低20%
}
```

### 5. 极端高温紧急保护

**新增保护机制:**
```javascript
// 回风温度 > 75°C 时
if (raTemp > 75) {
    Q_iec = Math.min(Q_iec, IEC_RATED_CAPACITY * 0.8);  // 降到额定的80%
    console.error('🚨 设备即将停机保护！');
}
```
