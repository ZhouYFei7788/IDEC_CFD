# 送风温度控制逻辑修正

## 问题描述

**之前的问题：**
- 送风温度设定：25°C
- 实际送风温度：10°C（严重过冷）
- 系统反应：增加风速 ❌（错误！）

## 根本原因

### 之前的错误逻辑

```javascript
// 错误：送风温度过低时，增加风速
if (saError < 0) {
    const lowTempBoost = Math.abs(saError) * 15;
    fanSpeed_actual += lowTempBoost;  // ❌ 错误！
}
```

**为什么错误？**

在IEC系统中：
- **风速↑** → 换热时间↓ → 温度更接近冷源 → **送风温度↓**
- **风速↓** → 换热时间↑ → 温度更接近回风 → **送风温度↑**

所以送风温度过低时增加风速，会让温度更低！

## 修正后的逻辑

### 新的控制策略

```javascript
// 正确：送风温度控制
if (saError < -2) {
    // 严重过冷（低于设定2度以上）
    // 大幅降低风速（每低1度，降低10%）
    fanSpeed_actual -= Math.abs(saError) * 10;
    fanSpeed_actual = Math.max(fanSpeed_actual, 20); // 最低20%
    
} else if (saError < 0) {
    // 轻微过冷
    // 适度降低风速（每低1度，降低5%）
    fanSpeed_actual -= Math.abs(saError) * 5;
    fanSpeed_actual = Math.max(fanSpeed_actual, 30); // 最低30%
    
} else if (saError > 2) {
    // 严重过热（高于设定2度以上）
    // 大幅增加风速（每高1度，增加10%）
    fanSpeed_actual += saError * 10;
    fanSpeed_actual = Math.min(fanSpeed_actual, 120); // 最高120%
    
} else if (saError > 0) {
    // 轻微过热
    // 适度增加风速（每高1度，增加5%）
    fanSpeed_actual += saError * 5;
    fanSpeed_actual = Math.min(fanSpeed_actual, 100); // 最高100%
}
```

## 工作原理

### 场景1：湿模式，送风温度10°C（设定25°C）

**问题分析：**
```
送风温度：10°C
设定温度：25°C
偏差：-15°C（严重过冷）

原因：
- 湿球温度：25°C
- IEC效率：95%
- 风速过高：100%
- CoreOut = RA - 0.85 × (RA - 25) ≈ 10°C（太低！）
```

**修正后的反应：**
```
1. 检测到saError = -15°C
2. 触发严重过冷逻辑
3. 降低风速：-15 × 10 = -150%
4. 风速降至最低：20%
5. 效率提高：0.95 - 0.2 × 0.10 = 0.93
6. CoreOut上升：RA - 0.93 × (RA - 25) ≈ 更接近RA
7. 送风温度逐渐上升到25°C ✓
```

### 场景2：干模式，送风温度30°C（设定25°C）

**问题分析：**
```
送风温度：30°C
设定温度：25°C
偏差：+5°C（过热）

原因：
- 室外温度：35°C
- 回风温度：40°C
- 风速过低：30%
- CoreOut太高
```

**修正后的反应：**
```
1. 检测到saError = +5°C
2. 触发过热逻辑
3. 增加风速：+5 × 10 = +50%
4. 风速提高到80%
5. 效率降低：0.75 - 0.8 × 0.15 = 0.63
6. CoreOut下降：RA - 0.63 × (RA - 35) ≈ 更接近OA
7. 送风温度逐渐下降到25°C ✓
```

## 控制策略总结

### 送风温度过低（过冷）

| 偏差 | 动作 | 风速变化 | 原因 |
|------|------|---------|------|
| -15°C | 严重过冷 | -150% → 20% | 风速太高，换热太强 |
| -5°C | 严重过冷 | -50% | 需要大幅降低风速 |
| -1°C | 轻微过冷 | -5% | 需要微调风速 |

**效果：风速↓ → 换热↓ → 温度↑**

### 送风温度过高（过热）

| 偏差 | 动作 | 风速变化 | 原因 |
|------|------|---------|------|
| +15°C | 严重过热 | +150% → 120% | 风速太低，换热不足 |
| +5°C | 严重过热 | +50% | 需要大幅增加风速 |
| +1°C | 轻微过热 | +5% | 需要微调风速 |

**效果：风速↑ → 换热↑ → 温度↓**

## 物理原理

### IEC换热过程

```
空气流经IEC芯体：

高风速（100%）：
RA(40°C) → [快速通过] → CoreOut(28°C)
换热时间短 → 温度变化小 → 接近RA

低风速（20%）：
RA(40°C) → [缓慢通过] → CoreOut(26°C)
换热时间长 → 温度变化大 → 接近冷源
```

### 效率公式

```javascript
efficiency = baseEff - (fanSpeed/100) × degradation

湿模式：
- 100%风速：0.95 - 1.0 × 0.10 = 0.85
- 50%风速：0.95 - 0.5 × 0.10 = 0.90
- 20%风速：0.95 - 0.2 × 0.10 = 0.93

干模式：
- 100%风速：0.75 - 1.0 × 0.15 = 0.60
- 50%风速：0.75 - 0.5 × 0.15 = 0.675
- 20%风速：0.75 - 0.2 × 0.15 = 0.72
```

## 优势

1. ✅ **精确控制** - 送风温度能够稳定在设定值
2. ✅ **自动调节** - 根据偏差自动调整风速
3. ✅ **分级响应** - 严重偏差大幅调整，轻微偏差微调
4. ✅ **安全限制** - 风速限制在20-120%范围内

## 注意事项

### 风速下限（20%）

- 太低的风速会导致风量不足
- 可能无法满足机房换气需求
- 如果送风温度仍然过低，需要切换模式

### 风速上限（120%）

- 超过100%表示超载运行
- 短时间可以，长期会损坏风机
- 如果送风温度仍然过高，需要开启DX

## 总结

**修正后的控制逻辑：**

- 🎯 **送风温度过低 → 降低风速**
- 🎯 **送风温度过高 → 增加风速**
- 🎯 **自动调节到设定值**

这才是正确的HVAC控制逻辑！
