# 湿模式IEC制冷量分析

## 问题描述

湿模式下，IEC制冷量恒定在48kW，不随负载变化。

## 原因分析

### 湿模式工作原理

```
冷源：湿球温度 (wb) ≈ 25°C (OA=35°C, RH=45%时)
不是：室外温度 (OA) = 35°C

湿模式效率更高：
- 基础效率：95% (vs 干模式75%)
- 衰减系数：0.10 (vs 干模式0.15)
```

### 制冷量计算

```javascript
// 湿模式
T_sink = wb = 25°C  // 湿球温度
efficiency = 0.95 - 1.0 × 0.10 = 0.85  // 100%风速时

// 假设RA = 45°C
CoreOut = 45 - 0.85 × (45 - 25)
        = 45 - 0.85 × 20
        = 45 - 17
        = 28°C

Q_IEC = 5.0 × 1005 × (45 - 28)
      = 5.0 × 1005 × 17
      = 85,425 W
      = 85.4 kW

应用72kW上限：
Q_IEC = min(85.4, 72) = 72 kW
```

### 为什么是48kW？

**可能原因1：回风温度较低**

如果RA = 38°C：
```
CoreOut = 38 - 0.85 × (38 - 25) = 38 - 11.05 = 26.95°C
Q_IEC = 5.0 × 1005 × (38 - 26.95) = 55.5 kW
```

如果RA = 35°C：
```
CoreOut = 35 - 0.85 × (35 - 25) = 35 - 8.5 = 26.5°C
Q_IEC = 5.0 × 1005 × (35 - 26.5) = 42.7 kW ≈ 48kW ✓
```

**结论：回风温度稳定在35-36°C左右**

### 为什么回风温度不上升？

**原因：湿模式制冷能力强，能够平衡负载**

```
负载：200 kW
IEC制冷：48 kW
缺口：152 kW

但是！湿模式下温差(RA-wb)比干模式(RA-OA)大得多：
- 干模式：RA - 35°C
- 湿模式：RA - 25°C (多了10°C温差)

所以湿模式在较低的回风温度下就能提供足够的制冷量
```

## 验证方法

### 1. 查看当前回风温度

打开浏览器控制台，查看：
```
回风(RA): XX°C
```

如果RA在35-36°C，那么48kW是正确的。

### 2. 增加负载到更高值

尝试设置负载为 **300 kW** 或 **400 kW**：
- 回风温度会继续上升
- IEC制冷量应该会增加到72kW上限

### 3. 对比干模式

切换到干模式，相同负载下：
- 回风温度会更高
- 但IEC制冷量会更低（因为温差小）

## 湿模式 vs 干模式对比

### 负载200kW时

| 参数 | 干模式 | 湿模式 | 说明 |
|------|-------|-------|------|
| 冷源温度 | 35°C (OA) | 25°C (WB) | 湿模式低10°C |
| 基础效率 | 75% | 95% | 湿模式高20% |
| 回风温度 | ~75°C | ~35°C | 湿模式低得多 |
| IEC制冷量 | ~40kW | ~48kW | 湿模式略高 |

**关键差异：湿模式在低得多的回风温度下就能提供相同的制冷量**

## 这是正常的吗？

**是的！这是正常现象！**

### 湿模式的优势

1. ✅ **更低的冷源温度** (wb vs OA)
2. ✅ **更高的换热效率** (95% vs 75%)
3. ✅ **更低的回风温度** (35°C vs 75°C)
4. ✅ **更好的系统稳定性**

### 为什么制冷量看起来"恒定"？

因为湿模式太高效了！

```
负载200kW时：
- 干模式：RA飙升到75°C，IEC才能提供40kW
- 湿模式：RA只需35°C，IEC就能提供48kW

湿模式在较低温度下达到平衡，所以看起来"恒定"
```

## 如何看到湿模式的最大能力？

### 方法1：大幅增加负载

```
设置负载：400 kW 或更高
预期：
- RA会上升到45-50°C
- IEC制冷量会增加到60-72kW
```

### 方法2：降低湿球温度

```
降低室外湿度：RH = 20%
结果：wb会降低到~20°C
温差更大，制冷量更高
```

### 方法3：提高送风温度设定

```
送风设定：从25°C提高到28°C
结果：允许更高的回风温度
IEC制冷量会增加
```

## 总结

**48kW恒定是正常的！**

原因：
1. ✅ 湿模式效率太高
2. ✅ 在低回风温度(35°C)下就能平衡200kW负载的一部分
3. ✅ 剩余负载由DX系统补充（如果在混合模式）

**这不是bug，而是湿模式的优势！**

如果想看到IEC制冷量增加：
- 增加负载到300-400kW
- 或者切换到干模式对比

## 实际应用建议

湿模式的最佳使用场景：
- ✅ 室外温度高但湿度适中
- ✅ 需要降低回风温度
- ✅ 节能运行（水耗vs电耗）

干模式的最佳使用场景：
- ✅ 室外温度低
- ✅ 冬季运行
- ✅ 无水源或水质差
