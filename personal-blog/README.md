# 个人博客

HVAC Engineer 个人主页项目，使用 Vue 3 + Tailwind CSS 构建。

## 项目结构

```
个人博客/
├── index.html          # 主入口文件
├── css/
│   └── style.css       # 自定义样式文件
├── js/
│   └── main.js         # Vue 应用逻辑
├── 1.html              # 原始代码备份
└── README.md           # 项目说明
```

## 技术栈

- **Vue 3** - 通过 CDN 引入，无需构建工具
- **Tailwind CSS** - 通过 CDN 引入，快速样式开发
- **Remix Icon** - 图标库
- **Google Fonts** - Inter 和 JetBrains Mono 字体

## 部署到 GitHub Pages

1. 将项目推送到 GitHub 仓库
2. 在仓库设置中启用 GitHub Pages
3. 选择 `main` 分支（或你的主分支）
4. 选择 `/ (root)` 作为源目录
5. 访问 `https://你的用户名.github.io/仓库名/` 即可查看

## 本地运行

直接在浏览器中打开 `index.html` 文件即可，无需任何构建步骤。

## 特性

- ✅ 响应式设计，支持移动端和桌面端
- ✅ 深色主题
- ✅ 项目卡片展开/收起动画
- ✅ 代码与样式分离，易于维护
- ✅ 无需构建工具，可直接部署
