### 1. 模块化架构
项目现在采用清晰的模块化结构：

```
src/
├── components/          # 组件目录
│   ├── Rack.tsx        # 机柜组件

│   ├── Scene.tsx       # 场景组件
│   └── Overlay.tsx     # UI 覆盖层
├── types.ts            # 类型定义
├── constants.ts        # 常量配置
├── utils.ts            # 工具函数
├── App.tsx             # 主应用
├── App.css             # 应用样式
├── index.css           # 全局样式
└── main.tsx            # 入口文件
```

