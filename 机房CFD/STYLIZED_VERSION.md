## 🔧 技术实现

### 机柜组件
```tsx
- BoxGeometry (主体)
- MeshToonMaterial (卡通材质)
- PlaneGeometry (玻璃门)
- EdgesGeometry (轮廓线)
- PointLight (状态灯光源)
```

### 电缆系统
```tsx
- Line 组件 (drei)
- 3条并行线 (L1/L2/L3)
- PointLight (末端发光)
- 发光颜色匹配相位
```

### 气流粒子
```tsx
- Points + BufferGeometry
- 100个粒子/系统
- useFrame 动画更新
- 冷气水平，热气垂直
```

### 列头柜 UI
```tsx
- Text 组件 (drei)
- 中文字体 (Noto Sans SC)
- 发光边框 (Line)
- 实时数据显示
```

### 后期处理
```tsx
<EffectComposer>
  <Bloom 
    luminanceThreshold={0.2}
    intensity={0.5}
  />
</EffectComposer>
```

## 🐛 故障排除

### 如果看不到模型
1. 刷新页面 (Ctrl/Cmd + Shift + R)
2. 检查控制台错误 (F12)
3. 确认 WebGL 2.0 支持

### 如果性能差
1. 减少区域数量
2. 减少粒子数量
3. 关闭 Bloom 效果

### 如果电缆不发光
- 检查 PointLight 是否启用
- 调整 intensity 参数
