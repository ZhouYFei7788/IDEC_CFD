# 🧪 测试版本 - 基础渲染验证

## 当前版本

这是一个**超级简化**的测试版本，用于验证基础 3D 渲染是否工作。

## 应该看到什么

如果 WebGL 正常工作，你应该看到：

1. ✅ **深蓝色背景** (#1a1a2e)
2. ✅ **深色地面** (大平面)
3. ✅ **青色网格线** (20x20 网格)
4. ✅ **4个彩色立方体**:
   - 中间：蓝色 (#3b82f6)
   - 右边：绿色 (#10b981)
   - 左边：橙色 (#f59e0b)
   - 后面：红色 (#ef4444)
5. ✅ **绿色发光球** (顶部)
6. ✅ **左上角UI** (黑色半透明卡片)

## 如果什么都看不到

### 1. 检查浏览器控制台
```
F12 → Console 标签
查找红色错误信息
```

### 2. 测试 WebGL 支持
访问: https://get.webgl.org/

如果显示 "WebGL is not available"，说明：
- 浏览器不支持 WebGL
- 显卡驱动问题
- WebGL 被禁用

### 3. 尝试其他浏览器
- Chrome (推荐)
- Firefox
- Edge

### 4. 硬刷新页面
- **Windows**: Ctrl + Shift + R
- **Mac**: Cmd + Shift + R

### 5. 清除所有缓存
```bash
# 停止服务器 (Ctrl+C)
rm -rf node_modules/.vite
rm -rf node_modules/.cache
npm run dev
```

### 6. 检查显卡设置
某些笔记本有双显卡，确保浏览器使用独立显卡。

## 如果能看到立方体

那太好了！说明基础渲染工作正常。我们可以逐步添加：
1. 更多机柜
2. 电缆线条
3. 粒子效果
4. 后期处理

## 如果只看到背景色

说明 Canvas 创建成功，但 3D 对象没有渲染。可能原因：
- 相机位置问题
- 光照问题
- 材质问题

## 调试步骤

### 步骤 1: 检查页面是否加载
打开浏览器开发者工具 (F12)，查看：
- Network 标签：所有资源是否加载成功
- Console 标签：是否有错误

### 步骤 2: 检查 Canvas 元素
在 Elements 标签中，应该能看到 `<canvas>` 元素。

### 步骤 3: 尝试交互
- 左键拖拽：应该能旋转视角
- 滚轮：应该能缩放
- 右键拖拽：应该能平移

如果能交互但看不到模型，说明模型在视野外。

### 步骤 4: 检查 Three.js 版本
```bash
npm list three
```

应该显示 three@0.182.0 或类似版本。
