# 磁悬浮压缩机技术平台

## 项目简介

本项目是一个专业的**Climaveneta (克莱门特) TECS2/SL-CA-E 0853/5 系列磁悬浮离心式压缩机**技术展示平台。

基于冷媒回路图纸 **F370853EYC05-O**，提供全面的技术参数、工作原理、组件详解和故障诊断信息。

## 技术栈

- ⚛️ **React 19** - 现代化UI框架
- 🎨 **Tailwind CSS** - 实用优先的CSS框架
- ✨ **Framer Motion** - 流畅的动画库
- 📊 **Recharts** - 数据可视化图表
- 🎯 **Lucide React** - 优质图标库
- ⚡ **Vite** - 极速开发构建工具

## 快速开始

### 安装依赖
```bash
cd 磁悬浮压缩机
npm install
```

### 开发模式
```bash
npm run dev
```

访问：`http://localhost:3002`

### 生产构建
```bash
npm run build
npm run preview
```
